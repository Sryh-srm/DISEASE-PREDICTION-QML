Hybrid Quantum Machine Learning Platform - UI Documentation

## Overview
This is a single-page React website showcasing a hybrid quantum machine learning platform for early disease detection. The UI consists of a main scrolling narrative page and a full-screen interactive demo modal that simulates quantum inference on patient cases.

**Technology/Framework**: React (with Vite), Lucide React for icons, CSS modules for styling
**Entry Point**: `src/main.jsx` → renders `<App />` into `#root`
**How to Run**: `npm install` then `npm run dev` (Vite development server)
**Main Application Structure**:
- `src/App.jsx`: Main layout orchestrator with state for loading and demo modal
- `src/components/`: All UI sections and reusable components
- `src/data/platformData.js`: Static demo data (pipeline stages, medical modules, benchmarks, patient cases)
- `src/styles/`: Component-specific CSS files
- `public/`: Static assets (favicon, icons)

## Major Screens/Pages/View
1. **Main Narrative Page** (default view): Scrollable sections covering:
   - Hero section with interactive quantum particle canvas
   - Pipeline stages (scroll-driven transformation architecture)
   - Problem statement (medical data complexity)
   - Hybrid approach (classical + quantum)
   - Quantum visualization (Bloch sphere + circuit simulator)
   - Medical data modalities (5 research modules)
   - Explainability & scientific integrity
   - Controlled experiment benchmark dashboard
   - Transition to interactive demo
2. **Interactive Demo Modal** (full-screen overlay): Quantum inference workbench for:
   - Selecting patient cases (3 synthetic cases)
   - Adjusting clinical feature vectors via sliders
   - Configuring quantum circuit (ansatz depth, entanglement topology)
   - Running simulation and viewing results:
     - Disease risk probability
     - Pauli-Z expectation values
     - Quantum Shapley feature attributions
     - Simulated quantum state telemetry

## 1. GENERAL
### Technology/Framework
- React 18 (functional components with hooks)
- Vite as build tool and dev server
- Lucide React for iconography
- CSS modules (via `.css` files imported in components)
- Plain JavaScript/JSX (no TypeScript)

### Entry Point
`src/main.jsx` creates React root and renders `<App />` with StrictMode.

### How to Run
1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Build for production: `npm run build` (outputs to `dist/`)

### Main Application Structure
- **App.jsx**: Controls global state (loading progress, demo modal visibility) and renders all sections in sequence
- **Navigation.jsx**: Fixed header with logo, nav links, system status, and demo launch button
- **Content Sections**: Each major topic is a separate component imported and rendered in order in `App.jsx`
- **InteractiveDemoModal.jsx**: Conditionally rendered full-screen modal when demo is opened
- **CosmicTunnelBackground.jsx**: Animated background canvas that serves as loading indicator and backdrop
- **Data Layer**: `src/data/platformData.js` exports static arrays/objects for pipeline stages, medical modules, experiment benchmarks, and patient cases
